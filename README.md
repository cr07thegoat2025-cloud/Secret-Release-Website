# TextChat website

One-page site for TextChat with a one-tap APK download.

The download button points at the latest release of
`cr07thegoat2025-cloud/Secret` (file `app-release.apk`) and shows the version,
size and date from the GitHub API. If no release exists yet, the button
shows "Not ready yet".

## Turn the site on

Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
branch `main`, folder `/ (root)`, then Save. The site appears at
https://cr07thegoat2025-cloud.github.io/Secret-Release-Website/
